# CallGuard

Live call security for HackGT 13 (team GeorgiaMellon). CallGuard checks whether the voice on your call is a real
person (**Hearsay**), stops your keystrokes from leaking through your microphone (**Keyguard**), and shows one
threat score on a live dashboard. It works with Zoom, Meet and Teams through virtual audio devices.

Status: phase 1 build (see `plans/`). Full README is written by WP8.
